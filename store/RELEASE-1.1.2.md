# YouChoose 1.1.2

- Moved **Summarize this video** onto the same row as the like/dislike, Share and native Ask/Gemini controls.
- The summary button remains independent of YouTube's menu. Native buttons keep their natural width; narrow windows can scroll the row horizontally instead of wrapping or removing controls.
- Turning YouChoose off restores the native row layout. Thumbnail fixes from 1.1.1 are retained.

Build with `sh store/package.sh` and upload `store/youchoose-1.1.2.zip` to the existing Chrome Web Store item. Existing settings and permissions are preserved. This package has not been submitted to the store.
